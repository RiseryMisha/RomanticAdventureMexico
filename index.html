📜 Before We Begin — The Rules

  1. This quest has 24 stages. Each one is its own separate challenge.
  2. If a stage gives you trouble, you can always ask me for a little help — free of charge, for anything small.
  3. For bigger trouble, you get 3 hints for the whole game. Each hint gives you either the password for the stage you're stuck on, or help with the task inside it — your choice. But hints aren't free, and each one costs more than the last:
    • Hint #1 — price: for one week (7 days) you set your in-game nickname to NoviaDeRizzy.
    • Hint #2 — price: for one week (7 days), every day before events you use the horn in the kingdom chat and write "Labubu Rizzy".
    • Hint #3 — price: steep. A pompitas photo.
    Important: the auto-complete password only works for tasks, games and puzzles that live inside this site itself. Anything done outside the site (photos, recipes, singing, and the like) can never be skipped with a password — a hint there only gives you help, not a free pass.
  4. Using the internet is fine — just don't lean on it more than you need to. In a quest like this, the process matters more than the result.
  5. AI is only allowed if you check with me first. Fair play, I hope!

There's no time limit, so use your hints wisely — some stages will feel easy at first, but the road gets tougher toward the end.

Good luck, and most of all — have fun. 💛
